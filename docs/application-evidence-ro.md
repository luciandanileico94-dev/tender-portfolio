## Dovezi principale

### Farm Registry Web + Python Tools

[Repository Web](https://github.com/luciandanileico94-dev/farm-registry-web) si [repository Python](https://github.com/luciandanileico94-dev/farm-registry-python-tools) formeaza impreuna demonstratia: un demo Web static cu date sintetice si un contract Python/FastAPI `GET /parcels`, cu raspuns GeoJSON, care poate fi testat separat conform README-ului. Nu este revendicat un API live deployat.

Stack-ul Web este React, TypeScript, React Query, Axios REST, Leaflet/GeoJSON si Vitest/RTL. Stack-ul Python este Python, FastAPI, Pydantic, Shapely/pyproj, REST/OpenAPI si pytest. Dovezi: [README Web](https://github.com/luciandanileico94-dev/farm-registry-web#readme) si [README Python](https://github.com/luciandanileico94-dev/farm-registry-python-tools#readme).

### Farm Registry Mobile

[Repository Mobile](https://github.com/luciandanileico94-dev/farm-registry-mobile) demonstreaza o coada si un istoric offline local folosind React Native, Expo, TypeScript si AsyncStorage. Nu include GPS, backend sau sincronizare guvernamentala. Dovada: [README](https://github.com/luciandanileico94-dev/farm-registry-mobile#readme).
